# 무사이 1차 사용성 테스트 계획

## 목적
대피 1세트(공습경보 → 지하 대피 → 화생방 → 경보해제)를 **처음 보는 사람이 안내만 보고 끝까지 해낼 수 있는지**,
그리고 **어느 단계에서 멈칫하는지** 찾는다. 1차 결과로 화면을 고친 뒤 같은 설문으로 2차 테스트를 해서 전후를 비교한다.

## 지표 (디자인 직군)
| 지표 | 정의 | 출처 |
|---|---|---|
| **과업 성공률** (주 지표) | 9개 단계 중 "혼자 바로" + "조금 헤매다" 비율. 단계별로도 계산 | 설문 "각 단계를 어떻게 해냈나요?" |
| 완료율 | "끝까지 완료했어요" 응답 비율 | 설문 "어디까지 진행했나요?" |
| 소요 시간 | 경보 시작 → 경보해제까지 (앱이 측정) | 완료 화면 "걸린 시간" |
| 안내 횟수 | 엘리베이터 선택 등 안내원이 바로잡아 준 횟수 (앱이 측정) | 완료 화면 "안내를 받은 횟수" |
| 학습 효과 | 퀴즈 4문항 정답 수, 체험 전 → 후 | 체험 전·후 퀴즈 |
| 쉬움(SEQ) · UMUX-Lite | 7점 척도 | 설문 |

## 참가자
- 5명 내외(리뷰 그룹 + 가족·지인). 휴대폰 1명 이상, 3D 게임 경험 적은 사람 1명 이상 포함.
- 개인정보는 받지 않는다. 참가자 번호(P1, P2…)만 쓴다.

## 진행 방법
1. 설문 링크를 보낸다(대면이면 옆에서 화면만 관찰, **도와주지 않는다**).
2. 참가자는 설문 1~3쪽(동의 · 정보 · 체험 전 퀴즈) → 서비스 체험 → 나머지 설문 순으로 진행.
3. 대면 진행이면 진행자는 멈칫한 장면과 혼잣말을 아래 표에 적는다.

| 참가자 | 단계 | 관찰한 행동 / 한 말 | 심각도(상·중·하) |
|---|---|---|---|
| P1 | | | |

## 퀴즈 정답
Q1 지하 대피시설이나 건물 지하 · Q2 비상계단 · Q3 높은 층 실내 · Q4 창문·문을 닫고 틈을 막고, 환풍기를 꺼요
(행정안전부 『비상시 국민행동요령』(2023) 12·20·32쪽)

## 구글폼 만들기
1. https://script.google.com → 새 프로젝트
2. [create-form.gs](create-form.gs) 내용을 붙여 넣고 저장
3. 함수 `createMusaiForm` 실행 → 권한 허용
4. 실행 로그의 **응답 주소**를 참가자에게 보낸다. 응답은 자동으로 스프레드시트에 쌓인다.

2차 테스트 때는 스크립트의 `ROUND`를 `'2차'`로 바꿔 한 번 더 실행하면 같은 문항의 새 폼이 생긴다.
