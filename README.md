# 무사이(MUSAI) — 대피 연습 3D

> 이름은 ‘무사히’에서 착안했어요. 안전하게 상황을 헤쳐 나가는 경험을 담았습니다.

공습경보부터 화학 상황, 경보해제까지 **대피 1세트**를 3D 공간에서 직접 걸으며 연습하는 웹 서비스입니다.
민방위 훈련 때 사람들을 따라 움직이기만 하고 **왜 그렇게 움직이는지는 몰랐던 경험**에서 시작했습니다.

## 핵심 흐름 (대피 1세트)
1. **평상시** — 10층 집에서 자유롭게 걸어 보기
2. **공습경보** — `1` 비상 가방 챙기기
3. **지하 대피** — 엘리베이터 대신 비상계단 (엘리베이터로 가면 안내원이 막고 이유 설명)
4. **대피소에서 방송 듣기** — `B`
5. **화학 상황 · 다시 위로** — `2` 코·입 가리기 → 높은 층으로 이동
6. **바깥 공기 막기** — 창문 닫기 · 문틈 막기 · 환풍기 끄기
7. **경보해제** — 회고 카드로 '왜' 4가지 복습

## 조작
| | 데스크톱 | 모바일 |
|---|---|---|
| 이동 | 바닥 클릭 · WASD/방향키 | 바닥 탭 |
| 둘러보기 | **마우스 오른쪽 버튼 드래그** (왼쪽 드래그도 가능) | 한 손가락 드래그 |
| 확대/축소 | 휠 | 두 손가락 핀치 |
| 동작 | `1` 가방 · `2` 코·입 · `3` 몸 낮추기 · `B` 방송 | 하단 버튼 |

## 실행
빌드 과정이 없는 정적 사이트입니다.
- `index.html`을 브라우저로 바로 열거나
- VS Code의 **Live Server** 확장으로 열면 됩니다.

주소 옵션
- `?lite` — 그림자를 끈 저사양 모드
- `?test` — 자동 테스트용 (시간 진행 빠르게)

## 폴더 구조
```
index.html            화면 뼈대(HUD, 로비, 카드)
src/style.css         밝은 학습용 카드 패널, 모바일 대응
src/config.js         서비스명 · 단계 · '왜' 문구 (서비스명은 여기서 바꿔요)
src/textures.js       나무 · 타일 · 콘크리트 · 창밖 풍경 · 표지판 (캔버스로 생성)
src/characters.js     치비 캐릭터 · 머리 장식 · 걷기/앉기 애니메이션
src/world.js          우리 집 · 10층 복도 · 지하 대피소 · 12층 실내
src/audio.js          사이렌(파상음) · 차임 · 음성 안내
src/main.js           카메라 · 조작 · HUD · 대피 1세트 흐름
vendor/three.min.js   three.js r160 (MIT)
tools/                Playwright 자동 테스트 (개발용)
```
