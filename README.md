# 무사이(MUSAI) — 대피 연습 3D

> 이름은 ‘무사히’에서 착안했어요. 안전하게 상황을 헤쳐 나가는 경험을 담았습니다.

**바로 써 보기 → https://mugee1.github.io/minbangwi/** (PC · 휴대폰 브라우저, 설치 없음)

공습경보부터 화학 상황, 경보해제까지 **대피 1세트**를 3D 공간에서 직접 걸으며 연습하는 웹 서비스입니다.
민방위 훈련 때 사람들을 따라 움직이기만 하고 **왜 그렇게 움직이는지는 몰랐던 경험**에서 시작했습니다.

## 핵심 흐름 (대피 1세트)
1. **평상시** — 10층 집에서 자유롭게 걸어 보기 (휴대폰은 터치 조작법 카드가 떠요)
2. **공습경보** — 비상 가방 챙기기 (아래 버튼 또는 선반 위 가방을 직접 누르기)
3. **지하 대피** — 복도에서 엘리베이터와 비상계단 중 직접 고르기 (엘리베이터를 고르면 이유 카드 후 계단 안내)
4. **대피소에서 방송 듣기** — 빈 자리에 앉아 라디오 켜기 → 공습경보 해제 방송 (다음 방송까지 남은 시간 표시)
5. **화생방경보 · 다시 위로** — 코·입 가리기 → 높은 층 실내로 이동 (사이렌 없이 음성방송)
6. **바깥 공기 막기** — 창문 닫기 · 문틈 막기 · 환풍기 끄기
7. **경보해제** — 회고 카드로 '왜' 4가지 복습

## 조작
| | 데스크톱 | 모바일 |
|---|---|---|
| 이동 | 바닥 클릭 · WASD/방향키 | 바닥 탭 |
| 둘러보기 | **마우스 오른쪽 버튼 드래그** (왼쪽 드래그도 가능) | 한 손가락 드래그 |
| 확대/축소 | 휠 | 두 손가락 핀치 |
| 동작 | 하단 버튼 또는 `1` 가방 · `2` 코·입 · `3` 몸 낮추기 · `B` 방송 | 하단 버튼 |
| 물건 | 비상 가방 · 라디오 클릭 | 비상 가방 · 라디오 탭 |

지금 눌러야 할 버튼은 노랗게 깜빡이고 "여기를 눌러요"가 떠요. 안내원 말풍선은 PC에서는 안내원 머리 위에, 휴대폰에서는 목표를 가리지 않게 화면 아래에 나와요.

## 실행
빌드 과정이 없는 정적 사이트입니다.
- `index.html`을 브라우저로 바로 열거나
- VS Code의 **Live Server** 확장으로 열면 됩니다.

주소 옵션
- `?lite` — 그림자를 끈 저사양 모드
- `?test` — 자동 테스트용 (느린 환경에서도 걷기가 끊기지 않게 한 프레임 이동 폭을 늘려요. 경보·방송 시간은 그대로)

자동 플레이 검증: `tools/drive.js`가 대피 1세트를 처음부터 끝까지 진행하며 단계별 스크린샷을 남겨요(Playwright 필요, 저장소에는 설치돼 있지 않음).

## 사용성 테스트 (1차)
계획·지표·퀴즈 정답은 [docs/usability-test/README.md](docs/usability-test/README.md), 구글폼 생성 스크립트는 [create-form.gs](docs/usability-test/create-form.gs)에 있어요.

| 지표 | 1차 결과 (10명) |
|---|---|
| 완료율 | 100% |
| 과업 성공률 (혼자 바로 + 조금 헤매다) | 96.7% (90건 중 87건) · 혼자 바로만 세면 87.8% (79건) |
| 처음 엘리베이터를 고른 비율 | 10% |
| 소요 시간 (경보 → 해제) | 평균 1분 54초 · 중앙값 1분 43초 (유효 응답 9건, 단위 없이 "3"만 적힌 1건 제외) |
| 체험 전 → 후 퀴즈 (4문항) | 평균 3.1 → 3.9 |

1차에서 찾아 고친 점
- 첫 행동 '가방' 찾기 (10명 중 5명 멈칫) → 버튼 이름으로 안내 · 깜빡임 강조 · 가방 직접 누르기
- 말풍선이 목표를 가림 → 휴대폰은 말풍선을 화면 아래에 고정
- 방송이 언제 끝나는지 모름 → '다음 방송까지 N초' 줄어드는 바

한계: 모든 수치는 참가자 자기 보고(설문) 기준이에요. 참가자가 모두 30대이고, 체험 직후 같은 퀴즈를 풀어 학습 효과가 커 보일 수 있어요. 고친 점의 효과는 아직 검증하지 않았고, 같은 설문으로 2차 테스트를 할 계획이에요.

## 폴더 구조
```
index.html            화면 뼈대(HUD, 로비, 카드)
src/style.css         다크 반투명 패널 + 노란 테두리, 모바일 대응
content.json          안내 문구 · 단계 · '왜' 문구 · 서비스명 (문구는 여기서만 고쳐요)
src/content.js        content.json을 옮긴 자동 생성 파일 (python tools/gen-content.py)
src/textures.js       나무 · 타일 · 콘크리트 · 창밖 풍경 · 표지판 (캔버스로 생성)
src/characters.js     치비 캐릭터 · 머리 장식 · 걷기/앉기 애니메이션
src/world.js          우리 집 · 10층 복도 · 지하 대피소 · 12층 실내
src/audio.js          사이렌(파상음) · 차임 · 경고음 · 음성 안내
src/main.js           카메라 · 조작 · HUD · 대피 1세트 흐름
vendor/three.min.js   three.js r160 (MIT)
docs/usability-test/  사용성 테스트 계획 · 구글폼 생성 스크립트
tools/                Playwright 자동 테스트 (개발용)
```
